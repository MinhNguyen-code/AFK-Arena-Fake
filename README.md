## 🎮 Giới thiệu

**Eternal Realms** là dự án game trên trình duyệt, được xây dựng để học tập và thử nghiệm thiết kế giao diện, quản lý nhân vật và hệ thống chiến đấu trong game nhập vai.

## ✨ Định hướng tính năng

- 🏰 **Sảnh game fantasy** — giao diện theo phong cách RPG cổ điển.
- 🦸 **Bộ sưu tập tướng** — xem, quản lý và nâng cấp nhân vật.
- ⚔️ **Auto-Battle 5v5** — sắp xếp đội hình và chiến đấu tự động.
- 🗺️ **Campaign** — vượt ải, nhận thưởng và mở khóa tiến trình.
- 🎒 **Trang bị & tài nguyên** — phát triển sức mạnh đội hình.
- ✨ **Triệu hồi tướng** — mở rộng bộ sưu tập bằng tài nguyên trong game.

> **Trạng thái:** Dự án đang phát triển; danh sách trên mô tả các tính năng hướng tới, không phải cam kết tất cả đã hoàn thiện.

## 🚀 Chạy dự án

**Yêu cầu:** Node.js và npm.

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển
npm run dev
```

Mở địa chỉ hiển thị trong terminal (dự án đang cấu hình cổng `3000`).

Đóng gói bản production:

```bash
npm run build
```
